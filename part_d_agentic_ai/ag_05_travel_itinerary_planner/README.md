# AG-05 — Travel Itinerary & Budget Multi-Agent

## 1. Overview
- **Domain**: Travel & Tourism
- **Spec**: Bleep Education Part D (Agentic AI)

### Problem Statement
Researches destinations, models multi-modal transit options, and generates cost-optimized travel itineraries with itemized estimates.

> **Disclaimer**: Travel planning assistant. Final credit card transactions require direct traveler authorization.

## 2. Multi-Agent Roles
- DestinationResearchAgent
- RoutePlannerAgent
- BudgetAuditor

## 3. Setup & Execution
```bash
pip install -r requirements.txt
pytest tests/ -v
streamlit run app.py
```
