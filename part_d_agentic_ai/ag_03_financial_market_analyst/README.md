# AG-03 — Financial Market Research Multi-Agent

## 1. Overview
- **Domain**: Finance
- **Spec**: Bleep Education Part D (Agentic AI)

### Problem Statement
Combines permitted financial data and news sentiment to produce traceable research reports without automated trade execution.

> **Disclaimer**: Financial research tool. Strictly prohibited from executing automated securities trades.

## 2. Multi-Agent Roles
- FundamentalAnalystAgent
- NewsSentimentAgent
- ComplianceAuditor

## 3. Setup & Execution
```bash
pip install -r requirements.txt
pytest tests/ -v
streamlit run app.py
```
