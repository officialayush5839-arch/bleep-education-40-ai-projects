## Universal Project Architecture

Every single project follows a strict industrial repository blueprint to guarantee maintainability, isolation, and reproducibility:

```
<project_directory>/
├── src/
│   ├── data_loader.py          # Deterministic synthetic data generation & loading
│   ├── preprocessor.py         # Pipeline transforms, scaling, chunking, or encoders
│   ├── model.py / agent.py     # Architecture definition, training loop, state machine
│   ├── evaluate.py             # Quantitative evaluation & metric calculation
│   └── utils.py                # Formatting helpers, safety checks, visualizations
├── tests/
│   └── test_*.py               # Automated pytest unit, integration & boundary tests
├── data/
│   └── *.csv / *.json          # Synthetic benchmark datasets matching target schemas
├── notebooks/
│   └── exploratory_analysis.ipynb # Interactive EDA, feature importance & ablations
├── results/
│   └── metrics.json / agent_trace.json # Serialized evaluation metrics & audit trails
├── reports/
│   └── project_report.pdf      # 12-section technical submission report (ReportLab)
├── app.py                      # Production Streamlit interactive web application
├── requirements.txt            # Project-specific pinned dependencies
├── .env.example                # Clean environment configuration template
└── README.md                   # Technical specification, API guide & instructions
```

## Installation & Environment Setup

### 1. Clone the Repository
```bash
git clone https://github.com/officialayush5839-arch/bleep-education-40-ai-projects.git
cd bleep-education-40-ai-projects
```

### 2. Create and Activate a Virtual Environment
```bash
# Windows (PowerShell)
python -m venv .venv
.venv\Scripts\Activate.ps1

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Core Dependencies
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Configure Environment Variables
```bash
cp .env.example .env
```

## 100-Mark Submission Rubric Alignment

Every project directory contains an autogenerated, professional 12-section technical submission report located at `<project_folder>/reports/project_report.pdf`, mapped directly to the Bleep Education evaluation rubric:

| Rubric Section | Weight | Covered Deliverables & Evidence |
|:---|:---:|:---|
| **1. Abstract & Executive Summary** | 10 Marks | Problem framing, domain impact, core architectural choice, and summary metrics. |
| **2. Problem Statement & Formulation** | 10 Marks | Mathematical problem specification, constraints, baseline expectations, and business objectives. |
| **3. Dataset Schema & Exploratory Analysis** | 15 Marks | Feature schemas, distribution plots, missing value handling, and exploratory notebooks (`.ipynb`). |
| **4. Feature Engineering & Preprocessing** | 10 Marks | Leakage-free transformations, scaling, tokenization, or sliding-window chunking. |
| **5. Model Architecture & Training Procedure** | 15 Marks | Hyperparameters, optimization algorithms, loss functions, and convergence checkpoints. |
| **6. Quantitative Results & Benchmark Metrics** | 15 Marks | Precision, Recall, F1, ROC-AUC, RMSE, R², Latency, and comparative baselines. |
| **7. Qualitative Analysis & Explainability** | 10 Marks | Feature importance (SHAP), error case inspection, attention maps, or agent trace logs. |
| **8. Ethical Implications & Bias Mitigation** | 5 Marks | Disparate impact analysis, demographic parity, privacy preservation, and clinical disclaimers. |
| **9. Deployment Architecture & UI Dashboard** | 5 Marks | Streamlit web application, inference latency benchmarking, and error-handling resilience. |
| **10. Future Work, Roadmap & References** | 5 Marks | Edge deployment, quantization, model compression, and formal academic citations. |

## Safety, Ethics & Governance

All projects in this repository enforce strict ethical boundaries:
- **Healthcare & Clinical Systems** (`ML-02`, `DL-03`, `GEN-02`): Explicitly annotated as diagnostic and screening support tools; non-substitutable for certified clinical review.
- **Legal & Financial Systems** (`GEN-04`, `GEN-05`, `AG-03`): Annotated as automated exploratory research assistants; non-substitutable for licensed legal or financial counsel.
- **Human-in-the-Loop (HITL)**: All high-stakes agent workflows (`AG-02` refund authorizations, `AG-08` network containment, `AG-09` purchase orders) mandate explicit human authorization gates.
