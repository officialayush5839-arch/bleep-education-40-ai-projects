# ML-02 — Hospital Patient Readmission Risk Prediction

## 1. Overview
- **Domain**: Healthcare
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Estimate 30-day patient readmission risk using hospital encounter history and treatment patterns to support post-discharge care planning.

> **Disclaimer**: Strictly restricted to educational and care-coordination planning. Not a clinical diagnostic decision tool.

## 2. Setup & Execution
```bash
pip install -r requirements.txt
pytest tests/ -v
streamlit run app.py
```
