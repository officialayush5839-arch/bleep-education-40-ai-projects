# ML-03 — Credit Card Fraud Detection

## 1. Overview
- **Domain**: FinTech
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Identify fraudulent credit card transactions while balancing detection sensitivity against false alarm operational costs under severe class imbalance.

> **Disclaimer**: Financial risk screening system. High-risk flagged transactions require secondary multi-factor verification.

pip install -r requirements.txt
