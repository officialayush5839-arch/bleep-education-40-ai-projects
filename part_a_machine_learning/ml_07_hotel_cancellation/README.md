# ML-07 — Hotel Booking Cancellation Prediction

## 1. Overview
- **Domain**: Hospitality
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Forecast hotel reservation cancellations using booking lead times, customer profiles, and rate structures to optimize dynamic room inventory.

> **Disclaimer**: Revenue management planning tool. Overbooking policies must comply with hospitality consumer standards.
