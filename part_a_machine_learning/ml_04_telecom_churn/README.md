# ML-04 — Telecom Customer Churn Prediction

## 1. Overview
- **Domain**: Telecommunications
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Predict customer attrition based on subscription tenure, contract structure, and billing data to recommend proactive retention interventions.

> **Disclaimer**: Business analytics model. Retention campaigns should be calibrated against customer lifetime value.
