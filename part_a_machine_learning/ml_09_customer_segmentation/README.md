# ML-09 — Retail Customer Segmentation

## 1. Overview
- **Domain**: Retail & E-Commerce
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Segment e-commerce customer transaction history into behavioral cohorts using Recency, Frequency, and Monetary (RFM) K-Means clustering.

> **Disclaimer**: Marketing intelligence segmentation. Segments should be refreshed on a monthly rolling window.

## 2. Setup & Execution
```bash
pip install -r requirements.txt
pytest tests/ -v
streamlit run app.py
```
