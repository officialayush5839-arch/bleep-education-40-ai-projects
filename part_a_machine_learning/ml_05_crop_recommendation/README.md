# ML-05 — Crop Recommendation System

## 1. Overview
- **Domain**: Agriculture
- **Spec**: Bleep Education Part A (Machine Learning)

### Problem Statement
Recommend optimal crop varieties based on soil chemical composition (N, P, K, pH) and micro-climatic environmental measurements.

> **Disclaimer**: Agronomic decision support system. Soil test lab validation and local weather advisory verification recommended.
